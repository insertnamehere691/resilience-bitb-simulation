# Resilience Inc. - Browser-in-the-Browser (BITB) Simulation

This repository contains a standalone, single-file Browser-in-the-Browser (BITB) phishing simulation landing page featuring custom corporate branding for Resilience Inc. 

## Project Overview
* **Purpose:** Built as part of an authorized security awareness training exercise to demonstrate visual spoofing techniques and the mechanics of Browser-in-the-Browser attacks.
* **Features:** 
  * Self-contained `index.html` file layout.
  * Draggable fake browser chrome window and secure address bar overlay.
  * Custom enterprise authentication form and alternative identity provider buttons.
  * Integration support to redirect captured form submissions to an educational training landing page.

## Usage
1. Ensure your corporate logo image file is named `logo.png` and placed in the same directory as `index.html`.
2. Open `index.html` locally in any web browser to test the draggable modal interface.
3. Configure the form submission handler to redirect users to the team's hosted educational feedback landing page.
